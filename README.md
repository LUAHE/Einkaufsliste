# Einkaufsliste PWA

## Auf GitHub Pages veröffentlichen

1. ZIP-Datei lokal entpacken.
2. Auf GitHub ein neues öffentliches Repository erstellen, zum Beispiel `einkaufsliste`.
3. Im Repository **Add file > Upload files** wählen.
4. Den **Inhalt des entpackten Ordners** hochladen. `index.html` muss direkt im Hauptverzeichnis liegen.
5. Unter **Settings > Pages** bei **Source** `Deploy from a branch` wählen.
6. Branch `main`, Ordner `/(root)` wählen und speichern.
7. Die veröffentlichte Adresse in Safari öffnen und über **Teilen > Zum Home-Bildschirm** installieren.

## Enthaltene Funktionen

- Artikel, Menge und Kategorie erfassen
- Offen/Erledigt filtern
- Nach Kategorie sortieren
- Liste teilen oder kopieren
- Lokale Speicherung im Browser
- Offline-Unterstützung
- Hell-/Dunkelmodus
- iPhone-Homescreen-Icon

Hinweis: Die Daten werden nur lokal im jeweiligen Browser gespeichert. Es gibt keinen Cloud-Sync zwischen mehreren Geräten.
